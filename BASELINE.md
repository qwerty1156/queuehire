# Проверка стартовой версии

Проверено при подготовке архива: Python 3.12, Linux, SQLite,
зависимости из requirements-lock.txt.

## Фактический результат

Команда: `python -m pytest -q`

- 24 passed — все smoke-проверки.
- 19 failed — опубликованные acceptance-требования пока не выполнены.
- 5 skipped — PostgreSQL-проверки без TEST_DATABASE_URL.
- 1 предупреждение зависимости Starlette/AnyIO; не причина failed-тестов.

Падения acceptance — часть задания. В архиве передаётся неисправленный
проект, а не готовое решение.

Дополнительно проверены:

- Компиляция Python-модулей.
- Миграция SQLite: upgrade head → downgrade base → upgrade head.
- Создание демо-аккаунтов и импорт 1000 исторических заданий.
- Аутентифицированный запрос списка через FastAPI TestClient.

## Стартовый замер списка

Данные: seed --large, tenant alpha, limit=20, без status-фильтра.

- HTTP 200.
- 23 SQL-запроса, включая авторизацию.
- 1032 загруженных ORM-объекта всех типов.
- Примерный elapsed: 0.044 секунды на машине подготовки.

Скрипт query_probe считает все типы ORM-объектов; acceptance-тест отдельно
считает загруженные объекты Job. Время зависит от машины и не является
порогом приёмки. Повтори замер в своём окружении до и после исправления.
